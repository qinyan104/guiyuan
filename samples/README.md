| `performance-test-500-persons.json` | 500 人 | 中型家族，测试性能与缩放 |
| `性能测试 - 1000人.json` | 1,000 人 | 千人级宗族规模测试 |
| `性能测试 - 2000人.json` | 2,000 人 | 两千人级大规模测试 |
| `性能测试 - 3000人.json` | 3,000 人 | 三千人级大规模测试 |
| `性能测试 - 4000人.json` | 4,000 人 | 四千人级大规模测试 |
| `性能测试 - 5000人.json` | 5,000 人 | 五千人级超大规模测试 |
| `性能测试 - 6000人.json` | 6,000 人 | 六千人级极限测试 |
| `性能测试 - 7000人.json` | 7,000 人 | 七千人级极限测试 |
| `性能测试 - 8000人.json` | 8,000 人 | 八千人级极限测试 |
| `性能测试 - 9000人.json` | 9,000 人 | 九千人级极限测试 |

## 导入方式

1. 启动系统，登录后进入 Dashboard
2. 点击「导入族谱数据」
3. 选择本目录下的 JSON 文件
4. 系统会自动解析人物、家庭关系并生成可视化树形图

## 数据说明

- 人物姓名、生卒年月为随机生成，仅供测试
- 包含完整的家庭关系（配偶、子女、父母）
- 不含真实个人信息
