# 归源商业化产品方向设计

**日期**：2026-06-20
**状态**：待用户审阅

## 1. 结论

归源的短期主线不是与成熟修谱公司竞争完整古籍出版，而是：

> 用无限画布高效整理家族关系，再一键生成适合分享和印刷的高质量族谱树成品。

产品由三个层级构成：

1. **核心工具**：无限画布修谱。
2. **首个付费产品**：族谱树海报导出。
3. **实验性高级功能**：古籍谱书出版。

OCR 暂不投入。只识别文字却不能形成待确认的人物关系，主要节省打字，不能解决修谱的核心困难。

## 2. 目标用户与服务边界

优先服务两类用户：

- 小家庭：整理几十至数百人的家族关系，分享或打印族谱树。
- 家族及修谱委员会：整理更大规模的数据，需要协作、审核、备份和专业导出。

归源提供自助软件，不承接人工修谱、人工排版和印刷履约。首期交付数字文件，不对接印刷厂。

## 3. 核心产品：无限画布修谱

无限画布负责建立和维护唯一的人物关系数据源。用户只描述人物及关系，系统负责排列位置和连接线，不要求用户手工摆放整棵树。

### 3.1 录入效率

- 选中人物后快速添加父母、配偶、儿子或女儿。
- 批量添加兄弟姐妹或子女，避免反复打开编辑弹窗。
- 新增后自动定位并高亮。
- 支持 GEDCOM 和 Excel 导入；Excel 提供字段映射和导入预览。
- 支持批量修改字辈、堂号等重复字段。

### 3.2 大谱浏览

- 折叠某个人的全部后代。
- 按房系、世代或始祖筛选。
- 快速跳转至始祖、本人、最近编辑人物和搜索结果。
- 缩小时显示简化节点，放大后显示完整资料。
- 支持整谱、局部分支和以某人为中心的浏览方式。

### 3.3 数据可靠性

- 提示可能的重复人物，但不自动合并。
- 检查循环关系、重复配偶、异常年龄、断代和关系冲突。
- 删除人物前展示受影响的关系。
- 提供可靠的撤销、自动保存、备份和版本恢复。
- 导出前检查缺失信息、隐私字段、文字溢出和缺字。

### 3.4 协作

- 普通家人可以只查看或提交纠错建议，不必学习完整编辑器。
- 谱主查看修改前后差异并接受或拒绝。
- 后续可为房系指定负责人，并标记待补充、待核实人物。

首期优先级为：快捷关系录入、批量子女、大谱折叠筛选、可靠撤销恢复。

## 4. 首个付费产品：族谱树海报

海报导出不是自由设计器，而是从现有族谱数据快速生成成品。

### 4.1 用户流程

1. 选择范围：整部族谱、某一房系、某人的祖先、某人的后代或当前画布范围。
2. 选择用途：手机长图、电脑浏览或印刷海报。
3. 选择少量样式，预览并导出。

关系数据只维护一次。进入导出流程后，用户不需要重新排列人物。

### 4.2 用户可调参数

- 横向或纵向。
- 紧凑、标准或宽松密度。
- 是否显示照片、生卒、配偶和排行。
- 标题、堂号、家训和落款。
- 在世人物隐私规则。
- 少量背景、字体和连接线样式。

### 4.3 系统自动处理

- 画布边界、留白、节点尺寸和文字换行。
- 超大族谱的缩放、裁切或分幅建议。
- 字体嵌入、图片清晰度和打印尺寸。
- 溢出、缺字和隐私检查。
- 不适合单页时明确建议缩减范围或分幅，不生成无法阅读的成品。

### 4.4 首期格式

- PNG：微信分享和电子收藏。
- PDF：家庭打印或交给印刷店。
- SVG：专业后期加工。

首期只维护一套现代样式和一套传统样式，不建设自由拖拽编辑器或大型模板市场。

## 5. 收费模式

先验证单次付费，再决定是否推出会员。

### 5.1 免费能力

- 无限画布基础编辑。
- 分享查看。
- 实时成品预览。
- 带水印、低分辨率 PNG。
- 用户数据导入和导出，不锁定用户数据。

### 5.2 单次购买

可测试以下价格区间：

- 高清 PNG：9.9–19.9 元。
- 印刷 PDF 与 SVG：39–69 元。
- PNG、PDF、SVG 套装：59–99 元。

最终价格根据预览到购买的转化率调整，不在首期建设复杂套餐系统。

### 5.3 后续会员

出现持续使用需求后，再提供家庭会员：

- 多次专业导出或导出额度。
- 更多协作者。
- 云端自动备份和历史版本。
- 导出记录与重复下载。

## 6. 隐私与数据所有权

隐私不是说明文案，而是产品能力。

### 6.1 本地私密模式

- 用户通过网页打开和保存本地族谱文件。
- 浏览器可使用 IndexedDB 保存临时恢复副本，但不能将其作为唯一正式存储。
- 人物关系、照片和导出渲染默认在浏览器中处理。
- 购买服务只验证账号和导出权益，不要求上传族谱正文。

现有 File System Access API 能力继续作为受支持浏览器中的优先方案；不支持时回退为文件上传和下载。

### 6.2 可选云端模式

- 只有用户主动开启协作或云备份时，族谱数据才上传。
- 界面持续显示当前是“仅本地”还是“已同步云端”。
- 分享链接默认脱敏，并允许设置有效期和撤销。
- 云端模式保留现有 OWNER、EDITOR、VIEWER 权限和审计能力。

### 6.3 用户承诺

- 用户可以随时导出完整数据。
- 删除云端族谱时，明确说明删除范围和备份保留期。
- 不将族谱数据用于训练模型、广告画像或出售。
- 日志不得记录人物正文、照片内容或完整族谱数据。

后续面向大型宗亲会时，可评估私有部署；首期不建设。

## 7. 防复制与商业护城河

网页界面和基础前端能力无法彻底防止截图复刻。产品不依赖隐藏按钮、JSON 加密或代码混淆建立商业模式。

归源的可持续价值来自：

- 持续优化的大谱布局和数据校验。
- 可靠的高清、印刷和分幅导出。
- 隐私、本地文件和云协作之间的完整体验。
- 官方模板、品牌、商标、更新和支持。
- 用户无需自己维护临时 AI Demo 的便利性。

基础 SVG 和用户数据保持可迁移。高级导出通过账号权益控制，但不声称不可绕过。现有 AGPL 授权与未来商业授权、商标和素材许可需保持清晰边界。

## 8. 古籍出版边界

古籍出版保留为实验性高级导出，不作为短期主战场。

短期只做：

- 修复字体、标点、分页和 PDF 一致性。
- 只维护一套可靠的传统竖排模板。
- 提供水印预览并记录真实使用需求。

短期不做：

- 更多仿古模板。
- 古籍 OCR。
- 自由排版编辑器。
- 印刷厂对接。
- 人工修谱和完整修谱服务。

只有当用户主动询价、现有预览产生付费或海报用户稳定进入成书流程时，才扩大投入。

## 9. 实施顺序

### 阶段一：核心体验

- 快捷关系录入和批量添加子女。
- 大谱折叠、房系筛选和快速定位。
- 撤销、恢复和本地文件体验。
- 数据校验与隐私检查。

### 阶段二：付费出口

- 族谱树海报预览。
- 导出范围与样式配置。
- PNG、PDF、SVG 的可靠生成。
- 水印预览、单次购买和重复下载。

### 阶段三：留存与协作

- 家人纠错审核。
- 云备份和历史版本。
- 更多协作者与会员额度。

### 阶段四：需求驱动支线

- 根据真实付费数据决定继续优化海报、协作或古籍成书。

## 10. 错误处理与质量门槛

- 导出失败不得扣除购买次数或额度。
- 已购买结果应允许在合理期限内重复下载。
- 本地文件写入失败时保留内存草稿并提示用户另存。
- 云同步冲突必须提供差异比较，不能静默覆盖。
- 超大谱导出需有明确上限和可执行的缩减或分幅建议。
- PNG、PDF、SVG 对同一配置的布局结果应一致。

## 11. 验证指标

第一阶段商业验证只看：

- 完成一定规模族谱的用户进入导出预览的比例。
- 预览用户购买无水印成品的比例。
- 用户最常选择整谱、房系、祖先还是后代导出。
- 导出失败率和退款原因。

若购买率低，优先检查成品质量、导出范围和价格，不继续增加无关功能。

## 13. 修订建议

以下为文档审阅后提出的待补充/待明确项。每条包含问题、影响和建议。

### 13.1 AGPL 授权与商业化边界

**问题**：文档第 7 节提到"现有 AGPL 授权与未来商业授权需保持清晰边界"，但没有具体落地方案。AGPL v3 要求通过网络向用户提供服务时，也必须提供对应源码。如果导出功能依赖服务端渲染（如 PDF 生成、大图合成），则该服务端代码必须开源。

**影响**：决定导出功能的技术架构和商业可行性。

**建议**：
- 导出渲染全部走**客户端路线**（浏览器端 Canvas/SVG → PNG/PDF），天然规避 AGPL 的网络分发义务。
- 后端只做账户验证和权益校验，不接触用户族谱数据的渲染过程。
- 如果后续必须做服务端渲染（如超大谱），将该模块以独立许可证发布，或作为闭源增值服务并取得所有贡献者同意。

### 13.2 超大族谱导出的性能与上限

**问题**：文档 4.3 提到"超大族谱的缩放、裁切或分幅建议"，但未定义上限和降级策略。浏览器端渲染 1000+ 节点的 SVG/PNG 存在内存和性能瓶颈。

**影响**：直接影响用户体验和付费转化。如果导出卡死或失败，用户不会付费。

**建议**：
- 明确导出节点上限：**免费版 200 节点，付费版 1000 节点**。
- 超限时：①提示缩减范围（按房系/世代筛选）；②自动建议分幅（每幅不超过上限）。
- 超过 500 节点时使用 Canvas 位图渲染替代 SVG DOM 渲染，降低浏览器内存压力。
- 首期不做服务端渲染，记录需求量后再评估。

### 13.3 分发与获客策略

**问题**：文档只定义了"做什么"，未涉及"怎么让用户找到归源"。修谱是极垂直的用户群体，没有自然流量。

**影响**：有产品没用户 = 零验证。

**建议**：
- 阶段二同步启动获客验证：
  - 在修谱相关微信群、QQ 群发布"免费族谱树长图生成器"（简化版导出），看自然传播和注册转化。
  - 在抖音/小红书发布"10 分钟做出家族世系图"的短视频教程。
  - 联系 2-3 个地方宗亲会做种子用户试用。
- 不投入 SEM/SEO，首期靠社群口碑验证。

### 13.4 小程序在商业化中的定位

**问题**：文档未涉及小程序的角色。当前小程序已有登录、查看、搜索、画布渲染功能，但未被纳入商业模型。

**影响**：小程序可能是用户分享和拉新的主要渠道，需要明确它与 Web 端的分工和付费边界。

**建议**：
- **小程序 = 查看 + 分享入口**（免费）：族谱查看、搜索、分享码查看。
- **Web = 编辑 + 导出**（付费）：画布编辑、海报导出、数据管理。
- 小程序中加入"在电脑上打开归源，生成海报"的引导，将用户导向 Web 付费出口。
- 小程序不做付费导出（支付流程复杂，且导出渲染更适合桌面浏览器）。

### 13.5 付费时机与转化设计

**问题**：文档 11 节提到"完成一定规模族谱的用户进入导出预览的比例"作为验证指标，但未定义触发条件和水印策略。

**影响**：付费引导过早赶走过晚漏掉转化。水印太重影响体验，太轻没有转化动力。

**建议**：
- **触发条件**：用户族谱达到 **30 人** 时，在首页出现"生成族谱海报"入口；达到 **100 人** 时，弹出一次引导提示。
- **水印策略**：免费预览使用**半透明斜纹水印**覆盖在节点区域（不遮挡连线和结构），让用户看到效果但不能直接使用。下载的免费 PNG 分辨率限制为 800px 宽。
- **付费引导**：预览页底部显示"去除水印并获取高清版本 ¥9.9"，一键购买，不跳转新页面。
- **验证指标具体化**：
  - "一定规模" = 30 人（最小可导出族谱）。
  - 关键转化漏斗：注册 → 建满 30 人 → 打开导出预览 → 下载免费版 → 付费购买。
