# 工作台控制区优化设计

## 目标

统一无限画布周围的按钮语言，修复实心按钮悬停时变白的问题，减少校验反馈对画布的遮挡，并优化亲属关系计算器的信息层级。

## 范围

本次只调整以下组件的模板与样式：

- `frontend/src/components/WorkbenchPanels.vue`
- `frontend/src/components/WorkbenchHeader.vue`
- `frontend/src/components/KinshipCalculatorDialog.vue`

不修改族谱数据结构、亲属关系计算逻辑、校验接口、画布交互或路由。

## 画布左侧控制区

左侧五个可见按钮采用同一套尺寸、圆角、边框、字体粗细和悬停反馈。默认状态使用暖白面板底色；只有当前打开的版式、历史或校验按钮使用朱砂红实心状态。

“回主谱”“全览”“关系”保持普通状态，不常驻朱砂红。悬停时使用浅朱砂背景、朱砂文字和轻微上移，不变成实心红色。

## 人物操作按钮

“编辑”保持朱砂红 `#c43a31`，“设为主支”使用产品强调色。两者的悬停状态必须保持各自底色，只通过亮度、阴影和轻微位移反馈，避免被通用按钮规则覆盖成白色。

“定位”保留次级按钮样式。

## 校验反馈

点击“校验”只切换左侧校验面板。加载、成功、错误和问题列表继续由现有 `ValidationPanel` 在面板内部展示。

删除 `WorkbenchPanels.vue` 中额外的右上角校验通知、远程校验请求状态和对应样式，避免重复请求、重复反馈和遮挡核心画布。

## 亲属关系弹窗

保留居中模态弹窗，不改成抽屉。弹窗采用更紧凑的谱牒卡片结构：

- 标题改为明确的“亲属关系”，副标题说明选择两位族人即可计算称谓。
- 两个人物选择区保持并列，明确展示“称呼者”和“被称呼者”，交换按钮置于中间。
- 计算结果优先展示，称谓作为视觉中心。
- 关系路径作为次级证据区，降低视觉重量并限制高度，长路径可横向滚动。
- 删除重复的遮罩样式，统一边框、阴影、圆角和朱砂强调色。
- 小屏幕继续纵向排列，并保留关闭、ESC 和点击遮罩关闭行为。

不修改现有搜索、交换、称谓计算、路径计算和空状态逻辑。

## 顶栏四按钮

“纪略”“编年”“考据”“付梓”组成一个紧凑分段操作组，共享外层面板、统一高度和相邻边界：

- “纪略”“编年”保持直接操作。
- “考据”“付梓”保留下拉菜单和箭头。
- 默认状态为透明暖白，悬停使用浅朱砂背景和朱砂文字。
- 打开的下拉按钮显示轻量激活状态。

协作者、主题切换和账号区域保持独立，不并入四按钮分段组。

## 可访问性与验证

保留现有按钮语义、`aria-expanded`、`aria-pressed`、键盘关闭和焦点行为。为主要交互补充一致的 `:focus-visible` 轮廓。

验证包括：

- 工作台与顶栏现有单元测试通过。
- Vue 类型检查与生产构建通过。
- 源码中不再存在校验通知的模板、状态或样式。
- 实心按钮的 hover 规则不会被通用规则覆盖。
