# 古籍排版可靠性第一阶段实施规格

Status: ready-for-agent

## Problem Statement

族谱编修者目前无法确信编辑预览就是最终成书结果。超长人物条目可能被截断或越出版心，世代标题可能独立留在一页，首选字体缺字时会出现方框，预览与 PDF 还可能产生不同的分页和栏位结果。与此同时，手动分页边界缺少可见、可删除的编辑表达，书稿修改后也没有完整的未保存保护。用户因此需要反复检查预览和 PDF，仍可能交付缺字、漏字、错页或未保存的谱书。

## Solution

以现有 `paginateBook()` 作为唯一的规范化排版入口，使它根据书稿、版式、手动分页符和字体覆盖情况，一次产出确定的书页、栏位、跨页片段及字体回退结果。人物条目优先整体换页，确实超过一页时按栏跨页续排；世代标题与该世第一条人物正文保持同页；缺失字形逐字符使用固定的全字形后备字体。编辑预览与矢量 PDF 共同消费同一排版结果，从而达到成书一致性。

编辑器同时把手动分页符呈现为可操作的非打印标记，并为正文、版式和分页符修改维护未保存状态。用户显式保存成功后清除该状态；返回、切换路由或关闭页面时，如果仍有修改，必须阻止静默丢失。

## User Stories

1. As a 族谱编修者, I want 人物条目的全部文字都进入谱书, so that 成书不会漏掉家族资料
2. As a 族谱编修者, I want 当前页剩余空间不足时将人物条目整体移到下一页, so that 可以优先保持条目完整和阅读连贯
3. As a 族谱编修者, I want 本身超过一整页的人物条目自动跨页续排, so that 长篇传记不需要人工拆成多个条目
4. As a 族谱编修者, I want 跨页续排保持原有字号, so that 长人物条目不会因为内容多而变得难以阅读
5. As a 族谱编修者, I want 跨页续排保持原始文字顺序, so that 人物生平不会在分页后错序
6. As a 族谱编修者, I want 跨页片段仍属于同一个人物条目, so that 编辑和保存时不会产生重复人物或碎片记录
7. As a 族谱编修者, I want 修改人物条目一次即可更新所有跨页内容, so that 不必分别维护每页的续文
8. As a 族谱编修者, I want 世代标题与该世第一条人物正文共同出现, so that 标题不会成为没有正文的孤页
9. As a 族谱编修者, I want 当前页放不下世代标题和至少一栏正文时二者一起换页, so that 世代结构保持清楚
10. As a 族谱编修者, I want 自动重排不截断或隐藏溢出的正文, so that 页面看似整齐时也不会悄悄丢字
11. As a 族谱编修者, I want 在两个逻辑块之间插入手动分页符, so that 可以控制重要内容从新页开始
12. As a 族谱编修者, I want 在编辑器中看见手动分页符, so that 能理解某处为何提前分页
13. As a 族谱编修者, I want 选择并删除手动分页符, so that 可以撤销不再需要的分页安排
14. As a 族谱编修者, I want 自动重排保留手动分页符的锚点, so that 修改前文后人工分页意图不会消失
15. As a 谱书读者, I want PDF 中不出现分页符操作标记, so that 成品只保留正式版心内容
16. As a 族谱编修者, I want 用户选择的字体始终作为首选字体, so that 谱书保持选定的书写风格
17. As a 族谱编修者, I want 首选字体缺少某个汉字时只回退该字符, so that 内容完整且整体风格变化最小
18. As a 族谱编修者, I want 中文标点缺失时也使用同一后备字体, so that PDF 不出现方框或空白标点
19. As a 族谱编修者, I want 预览和 PDF 使用相同的字体回退顺序, so that 导出后不会突然出现缺字或字体变化
20. As a 族谱编修者, I want 字体回退不替换整页字体, so that 个别缺字不会破坏整页版式风格
21. As a 族谱编修者, I want 预览与 PDF 具有相同页数, so that 可以依据预览确认成书规模
22. As a 族谱编修者, I want 预览与 PDF 具有相同分页位置, so that 每页内容归属在导出后保持不变
23. As a 族谱编修者, I want 预览与 PDF 具有相同的文字顺序和栏位, so that 竖排阅读次序不会因导出改变
24. As a 族谱编修者, I want 预览与 PDF 具有相同的字号和字体回退, so that 校订时看到的正文就是交付正文
25. As a 族谱编修者, I want 工作台背景、阴影和书脊只保留在编辑界面, so that PDF 不带入操作界面装饰
26. As a 族谱编修者, I want 修改正文后立即看到未保存提示, so that 知道当前书稿尚未持久化
27. As a 族谱编修者, I want 修改版式或分页符后也进入未保存状态, so that 所有影响成书的修改都受到保护
28. As a 族谱编修者, I want 返回画布或切换路由前收到未保存拦截, so that 不会因误操作丢失校订内容
29. As a 族谱编修者, I want 关闭或刷新浏览器页面前收到未保存拦截, so that 浏览器操作不会静默丢稿
30. As a 族谱编修者, I want 显式保存成功后清除未保存状态, so that 可以确认当前内容已经持久化
31. As a 族谱编修者, I want 保存失败后继续保留未保存状态, so that 不会把失败误认为保存成功
32. As a 族谱编修者, I want 现有书稿继续正常打开和排版, so that 排版升级不会要求重建已保存草稿
33. As a 族谱编修者, I want PDF 继续以矢量文字和线条导出, so that 成品保持清晰并适合印刷
34. As a 维护者, I want 相同书稿和版式总是得到相同的规范化排版结果, so that 排版问题可以稳定复现和测试
35. As a 维护者, I want 预览与 PDF 只负责呈现规范化排版结果, so that 两个成书路径不会再次产生不同算法

## Implementation Decisions

- 深化现有 `paginateBook()`，不新增第二套排版引擎。它是书稿自动排版的唯一规范化入口，也是主要测试缝。
- 规范化排版结果必须完整描述书页顺序、逻辑块位置、人物条目的跨页片段、栏位边界、字号以及每段文字实际使用的字体。相同输入必须产生相同结果。
- 人物条目先尝试放入当前页剩余空间；放不下但能在完整新页容纳时，整体移到下一页。
- 人物条目本身超过完整单页容量时，按可用栏位跨页续排。续排不得截断正文、隐藏溢出内容或缩小字号。
- 每个跨页片段保留对原人物条目的稳定关联及连续文字范围。跨页片段只属于派生排版结果，不成为新的可保存人物条目。
- 编辑仍作用于原始人物条目；重新排版负责重新生成全部跨页片段。
- 世代标题采用“与下一正文保持同页”规则。当前页不能同时容纳标题和至少一栏该世第一条人物正文时，标题与第一条人物正文一起移至下一页。
- 手动分页符锚定在两个逻辑块之间，属于可保存的书稿编辑内容。自动重排必须遵守该边界，不得把它转换为空白正文或无来源空白页。
- 编辑器将手动分页符显示为非打印标记，并提供选择和删除能力；预览正式版心及 PDF 均不绘制标记本身。
- 用户选定字体是首选字体。排版阶段按字符检查字形覆盖；缺失的汉字或标点仅使用一套固定的全字形 CJK 后备字体。
- 预览和 PDF 必须消费排版阶段确定的同一字体选择结果，不允许渲染器自行采用不同的隐式字体回退。
- 优先复用项目已具备且授权允许随成品使用的 CJK 字体资源；若现有字体无法保证覆盖，则只引入一套固定后备字体资源，不增加字体管理框架。
- Vue 预览和矢量 PDF 保持为薄渲染器，共同消费规范化排版结果；不得使用 DOM 截图替代矢量 PDF，也不得继续维护独立的分页算法。
- 成书一致性覆盖页数、分页位置、文字顺序、栏位、字号和字体回退。工作台背景、书脊、阴影、选中态和分页符标记等界面装饰不在一致性范围内。
- 正文、版式设置或手动分页符发生变化后，书稿立即进入未保存状态。初次载入、初次生成或最近一次保存成功的书稿作为已保存基线。
- 工具栏明确显示未保存状态。保存成功后更新基线并清除状态；保存失败时保留未保存状态和当前编辑内容。
- 路由返回、路由切换以及浏览器刷新或关闭都必须在未保存时触发离开保护，防止静默丢稿。
- 第一阶段继续采用用户显式保存，不增加自动保存、后台重试或多端冲突合并。
- 沿用现有书稿数据和保存接口。除了承载手动分页符所必需的最小文档结构调整外，不引入新的后端业务实体或独立排版存储。

## Testing Decisions

- 主要测试缝是 `paginateBook()` 的外部输入与规范化排版结果。测试只断言可观察行为，例如页数、分页边界、文字顺序、栏位、片段来源和字体选择，不锁定内部辅助函数或循环实现。
- 使用项目现有的 Vitest 纯模块测试模式覆盖排版计算；优先采用少量表格化案例，不为每个内部函数建立单独测试层。
- 覆盖人物条目恰好装满剩余空间、剩余空间不足而整体换页、能在新页完整容纳，以及超过整页后跨多页续排的边界案例。
- 对跨页续排断言全文只出现一次、顺序连续、字号不变、所有片段仍指向同一人物条目，且没有内容被截断或隐藏。
- 覆盖世代标题与第一栏人物正文共同换页，防止再次产生只有世代标题的孤页。
- 覆盖手动分页符的插入边界、自动重排后仍保留、删除后恢复自动流动，以及规范化成书内容不包含操作标记。
- 覆盖首选字体完全支持、部分字符缺失、中文标点缺失和连续混合字体片段，断言只对缺失字符使用固定后备字体。
- 用同一份规范化排版结果分别驱动预览和 PDF 的集成测试，至少核对页数、页面内容顺序、栏位、字号与字体选择一致；不采用脆弱的像素级截图作为主要断言。
- 覆盖正文、版式和分页符修改都会进入未保存状态，保存成功会清除状态，保存失败会保留状态。
- 使用项目现有的路由与浏览器 E2E 测试方式覆盖返回、路由切换、刷新或关闭前的未保存保护，以及确认离开和取消离开的两条路径。
- 保留一条包含多世人物、超长人物条目、缺失字形和手动分页符的代表性回归用例，验证排版到 PDF 的完整主路径。
- 现有书稿载入、编辑、保存和矢量 PDF 导出测试必须继续通过，证明该阶段没有改变既有书稿的基本契约。

## Out of Scope

- 新增谱书章节、内容类型或生成规则
- 新增古籍模板、主题或整体视觉重设计
- 自动保存、定时保存、后台重试和离线同步
- 多人协作、版本合并和并发冲突处理
- 像素级复刻编辑工作台的阴影、书脊、背景或选中态到 PDF
- 用 DOM 截图或位图页面替代现有矢量 PDF
- 重写整套书稿编辑器或建设通用桌面排版引擎
- 解决与本阶段排版可靠性无关的接口版本化、数据库并发建稿或前端包体积问题

## Further Notes

- 本阶段以内容完整、稳定字号和成书一致性为验收优先级，视觉润色排在其后。
- 现有书稿是可编辑事实来源；书页、栏位、跨页片段及字体选择都是可重复生成的派生结果，不应作为第二份可编辑内容保存。
- 实施时应先让规范化排版测试失败，再以最小改动深化现有排版入口，随后让预览和 PDF 消费该结果，最后补上编辑器的分页符操作及未保存保护。
