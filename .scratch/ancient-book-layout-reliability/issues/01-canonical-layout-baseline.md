# 01 — 建立共享的规范化排版基线

**What to build:** 让现有简单书稿通过唯一的规范化排版入口生成书页，并由编辑预览和矢量 PDF 共同消费这份结果。在不改变现有简单书稿成书效果的前提下，为后续排版可靠性能力建立一个稳定、可测试的纵向基线。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 相同书稿和版式输入会稳定产生相同的书页数量、内容顺序、栏位和字号结果
- [x] 规范化排版结果能够表达书页、逻辑块、栏位及实际字体选择，后续能力不需要另建排版模型
- [x] 编辑预览与矢量 PDF 均消费同一份规范化排版结果，不再各自决定分页
- [x] 现有简单书稿的载入、编辑、保存、预览和矢量 PDF 导出行为保持可用
- [x] 在 `paginateBook()` 这一最高层测试缝留下可运行的回归测试，断言外部排版行为而非内部实现

## Answer

`paginateBook()` 现在产出包含书页、页面度量、逻辑块、栏位和字体运行的规范化结果。编辑预览与矢量 PDF 均直接消费该结果；人物条目非编辑态按规范化栏位显示，编辑态仍写回原人物条目。新增的公开缝回归测试覆盖固定输入、确定输出和当前字体/栏位结果。

验证：前端 58 个测试文件、277 项测试通过；生产构建通过；双轴代码审查无剩余发现。npm 官方审计另报告 9 个既有依赖漏洞，未在本票内升级依赖。
