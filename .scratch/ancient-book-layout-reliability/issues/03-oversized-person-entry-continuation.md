# 03 — 让超长人物条目跨页续排

**What to build:** 让本身超过完整单页容量的人物条目按栏跨页续排，同时保持原有字号、正文顺序和单一人物条目身份。用户编辑的仍是原条目，预览和 PDF 则完整呈现所有续排内容。

**Blocked by:** 02 — 保证人物条目完整换页和世代标题同行

**Status:** resolved

- [x] 超过完整单页容量的人物条目会自动生成连续的跨栏、跨页片段
- [x] 按顺序拼接全部跨页片段后与原人物条目正文完全相同，文字只出现一次且没有遗漏
- [x] 所有跨页片段保持原有字号，并稳定关联同一个人物条目
- [x] 跨页片段只存在于派生排版结果中，不会保存成多个可编辑人物条目
- [x] 修改原人物条目后会重新生成全部续排片段，不需要逐页编辑
- [x] 编辑预览和矢量 PDF 均完整呈现续排正文，不发生裁切、越出版心或静默隐藏
- [x] 回归测试覆盖跨两页和跨多页的长人物条目

## Answer

超长人物条目按规范化栏位跨页切分，所有片段复用同一源条目、索引和字体信息；编辑数据仍只有一个人物条目，修改后由分页器重新生成片段。预览与 PDF 直接消费同一份续排结果。

验证：覆盖跨两页、跨多页、内容顺序、身份关联和重新分页；前端 58 个测试文件、280 项测试通过，生产构建通过，双轴代码审查无发现。依赖审计仍报告 9 项既有漏洞（8 高危、1 严重），未自动修改依赖。
