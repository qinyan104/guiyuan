# 07 — 验收完整书稿的成书一致性

**What to build:** 用一份包含多世人物、超长人物条目、缺失字形和手动分页符的代表性书稿完成整条成书路径，消除各能力组合后残留的预览与 PDF 差异，并为第一阶段留下可重复执行的交付回归。

**Blocked by:** 03 — 让超长人物条目跨页续排；04 — 让缺失字形逐字符回退；06 — 保护书稿未保存修改

**Status:** ready-for-agent

- [ ] 代表性书稿能够完成载入、编辑、手动分页、显式保存、重新打开、预览和矢量 PDF 导出
- [ ] 编辑预览与 PDF 的页数、分页位置、文字顺序、栏位、字号和字体回退一致
- [ ] 成品中不存在孤立世代标题、正文裁切、越出版心、缺字方框、静默丢字或分页符操作标记
- [ ] 跨页人物条目的全部正文按原顺序出现且只出现一次
- [ ] 工作台背景、阴影、书脊和选中态不作为 PDF 一致性要求，也不会进入成品内容
- [ ] 代表性回归可自动重复运行，不依赖人工像素比对作为主要判断
- [ ] 现有书稿相关测试、前端测试和生产构建全部通过
