# 02 — 保证人物条目完整换页和世代标题同行

**What to build:** 当当前页剩余空间不足时，优先把能够在完整新页容纳的人物条目整体移到下一页；同时保证世代标题与该世第一条人物正文共同出现，让预览和 PDF 都不再产生截断条目或孤立标题页。

**Blocked by:** 01 — 建立共享的规范化排版基线

**Status:** resolved

- [x] 人物条目能放入当前页时正常连续排入，不产生多余换页
- [x] 人物条目放不下当前页但能放入完整新页时整体换页，正文不被拆分、截断或隐藏
- [x] 当前页容不下世代标题和至少一栏首条人物正文时，两者共同移到下一页
- [x] 不会生成只有世代标题而没有该世人物正文的书页
- [x] 编辑预览与矢量 PDF 的相关页数、分页位置、内容顺序和栏位一致
- [x] 边界测试覆盖恰好装满、剩余空间不足以及标题同行规则

## Answer

普通人物条目在完整新页可容纳时整体换页；世代标题会优先为首条人物保留完整栏数，超出单页时至少与首栏同行。预览与 PDF 继续共用规范化分页结果。

验证：前端 58 个测试文件、280 项测试通过，生产构建通过，双轴代码审查无发现。依赖审计仍报告 9 项既有漏洞（8 高危、1 严重），未自动修改依赖。
